# Simulador de Batalla Yu-Gi-Oh!

Proyecto académico para el examen final de Programación Orientada a Objetos. Implementa MVC, combate entre monstruos, persistencia en `historial_combate.txt`, pruebas JUnit y una interfaz Swing diseñada para ser abierta/modificada como JFrame Form de NetBeans.

## Ejecución

1. Abrir la carpeta como proyecto Maven en NetBeans.
2. Ejecutar `edu.uao.yugioh.Main`.
3. Para pruebas: `mvn test`.

La aplicación inicia dos jugadores con 8000 LP. Seleccione cartas, posiciones y pulse **Atacar**. El historial se guarda en la carpeta de ejecución.

## Git

La carpeta está preparada para Git. Cree un repositorio en GitHub y agregue la URL en el campo correspondiente de la entrega.
